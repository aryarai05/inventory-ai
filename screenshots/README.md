# Dashboard Screenshots

This folder contains visual previews of the **AI-Powered Inventory Demand Forecasting & Optimization System** Streamlit application:

1. `01_executive_overview.png`: Executive S&OP Summary with KPI cards and enterprise sales trends.
2. `02_demand_forecasting.png`: Product forecast with 95% confidence intervals and historical actuals.
3. `03_inventory_intelligence.png`: Risk classification matrix with safety stock buffers and audit reasons.
4. `04_product_deepdive.png`: SKU unit economics, supplier reliability, and inventory movement curves.
5. `05_replenishment_optimization.png`: Interactive PuLP Mixed-Integer Linear Programming solver results.
6. `06_model_leaderboard.png`: Out-of-sample forecasting leaderboard and feature importances.
7. `07_sql_explorer.png`: Real-time SQL query console connected to `data/inventory.db`.
