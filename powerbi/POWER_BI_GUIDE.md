# Power BI Integration & Dashboard Implementation Guide

This guide describes how to connect Microsoft Power BI Desktop to the production-ready datasets generated by the **AI-Powered Inventory Demand Forecasting & Optimization System**.

---

## 1. Data Model & Star Schema Architecture

Connect Power BI to the 4 cleaned CSV files located in `powerbi/`:

```
           +-----------------------------+
           |       product_metrics       |  (Dimension Table)
           |-----------------------------|
           | product_id (PK)             |
           | product_name                |
           | category                    |
           | unit_cost, unit_price       |
           | lead_time_days              |
           | risk_level                  |
           +-----------------------------+
                     | 1
                     |
                     | *
+------------------------------------+        +-----------------------------------+
|      forecast_dashboard_data       |        |     inventory_dashboard_data      | (Fact)
|------------------------------------|        |-----------------------------------|
| date                               |        | date                              |
| product_id (FK)                    |        | product_id (FK)                   |
| predicted_demand                   |        | current_inventory                 |
| lower_bound, upper_bound           |        | safety_stock, reorder_point       |
+------------------------------------+        | days_of_supply                    |
                                              | daily_holding_cost                |
                                              +-----------------------------------+
                                                               |
                                                               | (Cross-filter)
                                                               v
                                              +-----------------------------------+
                                              |         regional_metrics          |
                                              |-----------------------------------|
                                              | region_id (PK)                    |
                                              | region_name, warehouse_id         |
                                              | total_units_sold, total_revenue   |
                                              | stockout_rate_pct                 |
                                              +-----------------------------------+
```

## 2. Core DAX Measures Specification

Create the following measures in a dedicated `_Measures` table in Power BI:

### Measure 1: Total Forecasted Demand
```dax
Total_Forecasted_Demand = 
SUM(forecast_dashboard_data[predicted_demand])
```

### Measure 2: Total On-Hand Inventory Units
```dax
Total_On_Hand_Inventory = 
SUM(inventory_dashboard_data[current_inventory])
```

### Measure 3: Total Working Capital Tied in Inventory
```dax
Total_Inventory_Value = 
SUMX(
    inventory_dashboard_data, 
    inventory_dashboard_data[current_inventory] * RELATED(product_metrics[unit_cost])
)
```

### Measure 4: Total Recommended Reorder Units
```dax
Total_Recommended_Reorder = 
SUM(product_metrics[optimal_reorder_qty])
```

### Measure 5: Stockout Risk Count
```dax
Critical_Risk_SKU_Count = 
CALCULATE(
    DISTINCTCOUNT(inventory_dashboard_data[product_id]),
    inventory_dashboard_data[risk_level] = "CRITICAL STOCKOUT RISK"
)
```

### Measure 6: Annualized Inventory Turnover Ratio
```dax
Inventory_Turnover = 
DIVIDE(
    [Total COGS], 
    [Total_Inventory_Value], 
    0
)
```

## 3. Recommended Canvas Layouts & Visuals

### Page 1: Executive S&OP Summary
- **KPI Cards (Top Banner)**: Total Working Capital ($), Total Forecasted 14-Day Demand, Total SKUs Requiring Reorder, Critical Stockout Alerts.
- **Visual 1 (Donut Chart)**: Inventory Risk Distribution (`product_metrics[risk_level]`).
- **Visual 2 (Clustered Column Chart)**: Total Revenue and Stockout Rate by Region (`regional_metrics`).
- **Visual 3 (Matrix Grid)**: Top 10 SKUs requiring immediate purchase order placement with Lead Time, Current Stock, and Suggested Order Qty.

### Page 2: Demand Forecast & Replenishment
- **Slicers**: Product Category (`product_metrics[category]`), Product Name (`product_metrics[product_name]`).
- **Visual 1 (Line Chart with Confidence Ribbon)**: 
  - X-Axis: `forecast_dashboard_data[date]`
  - Values: `predicted_demand`
  - Shaded Error Area: `lower_bound` to `upper_bound`
- **Visual 2 (Gauge / Bullet Chart)**: Current Inventory vs. Reorder Point & Safety Stock targets.

### Page 3: Optimization & Financial Trade-Offs
- **Visual 1 (Stacked Bar Chart)**: Total Holding Cost vs. Fixed Order Cost vs. Stockout Penalty by Merchandise Category.
- **Visual 2 (Scatter Plot)**: Days of Supply (X-Axis) vs. Holding Cost (Y-Axis), bubble size by Revenue. Highlights overstocked vs critical capital traps.
