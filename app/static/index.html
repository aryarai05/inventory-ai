Senior Data Science & Supply Chain Analytics Highlights

Methodology, mathematical formulations, and engineering principles implemented in this platform.

1. Zero-Lookahead Feature Engineering

In time-series demand forecasting, unshifted rolling windows leak future information into the training set. This system computes all rolling aggregates on shift(1) (rolling_mean_7, rolling_std_7), ensuring today's demand is never observed during training.

2. Mixed-Integer Linear Replenishment Optimization

Formulated as a Mixed-Integer Linear Program (MILP) in PuLP, balancing daily inventory holding cost ($h$), fixed order placement cost ($K$), and stockout shortage penalties ($p$) across planning horizons subject to vendor lead times ($L$).

3. Strict Chronological Model Validation

Random cross-validation invalidates temporal integrity. Models are benchmarked on 8,250 out-of-sample future records (First 70% Train, Next 15% Validation, Final 15% Test). Weighted Absolute Percentage Error (17.51% WAPE) guarantees reliable performance.

4. MLOps Experiment Tracking & PySpark Ready

Tracked with MLflow (sqlite:///mlruns.db). Includes a distributed PySpark windowed feature engineering pipeline and Databricks Delta Lake notebook in src/spark/ for big-data scale.

Mathematical Optimization Formulation (PuLP MILP)
Minimize:  ∑ [ h · I_t + K · Y_t + p · S_t ]  for t = 1 ... H

Subject to:
  • Inventory Conservation:   I_t = I_{t-1} + Q_{t-L} - d̂_t + S_t   ∀ t
  • Big-M Order Linking:      Q_t ≤ M · Y_t                           ∀ t
  • Minimum Order Batch:      Q_t ≥ MOQ · Y_t                         ∀ t
  • Variable Domains:         Q_t ≥ 0,  I_t ≥ 0,  S_t ≥ 0,  Y_t ∈ {0, 1}
