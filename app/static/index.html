Senior Data Science & Supply Chain Engineering Competencies

Architectural breakdown and production design principles demonstrated in this project

1. Zero-Lookahead Feature Engineering

In time-series demand forecasting, rolling statistics computed without shift inadvertently leak future target values into the training matrix. This pipeline applies strict shift(1) before any rolling calculation (rolling_mean_7, rolling_std_7), ensuring today's demand is never observed during training.

2. Mathematical Replenishment Optimization (PuLP)

Unlike simplistic static reorder rules, replenishment lot sizing is formulated as a Mixed-Integer Linear Program (MILP). The solver dynamically balances inventory holding capital against fixed purchase order placement fees and shortage costs subject to lead time delivery lags.

3. Strict Chronological Evaluation

Random K-Fold cross-validation destroys temporal structure. Models are evaluated chronologically on 8,250 out-of-sample future records (First 70% Train, Next 15% Validation, Final 15% Test). Weighted Absolute Percentage Error (17.51% WAPE) guarantees safe performance in sparse demand days.

4. Production MLOps & Distributed Spark Support

Full experiment lifecycle is tracked via MLflow (mlruns.db). For big data scale, a PySpark feature pipeline with window specifications and a Databricks Delta Lake Medallion notebook are provided in src/spark/.

Mathematical Formulation (PuLP Mixed-Integer Linear Program)

Minimize: ∑ [ h · I_t + K · Y_t + p · S_t ] for t = 1 ... H

Subject to:
  • Inventory Balance:      I_t = I_{t-1} + Q_{t-L} - d̂_t + S_t
  • Big-M Order Linking:    Q_t ≤ M · Y_t
  • Minimum Order Batch:    Q_t ≥ MOQ · Y_t
  • Variable Domains:       Q_t ≥ 0, I_t ≥ 0, S_t ≥ 0, Y_t ∈ {0, 1}
